## Descripción

Aplicación de escritorio para administrar categorías y productos de una tienda. Guarda la información en SQL Server.

## Tecnologías

- C#
- Windows Forms con .NET 10
- SQL Server Express
- Microsoft.Data.SqlClient

## Requisitos

- Visual Studio con soporte para Windows Forms y .NET 10
- SQL Server Express y SQL Server Management Studio

## Base de datos

1. En SSMS, crea una base de datos llamada `GestionProductosDB`.
2. Abre y ejecuta `GestionProductosDB.sql` sobre esa base vacía.
3. La aplicación se conecta a `localhost\SQLEXPRESS` con autenticación de Windows.

## Funcionalidades

- CRUD de categorías y productos.
- Búsqueda de productos por nombre.
- Validación de datos.
- Cálculo del valor del inventario: precio por stock.
